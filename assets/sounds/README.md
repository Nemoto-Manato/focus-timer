# 効果音アセットについて

当初は雨音/カフェ/扇風機を`.mp3`ファイルとして同梱する計画だったが、外部音源を
調達・ライセンス確認する手間とリスクを避けるため、2026-08-19付けで方針変更。

現在は4種類のサウンド（雨音、ブラウンノイズ、カフェ、扇風機）すべてを
`js/audio.js`内でWeb Audio APIによりその場で音声合成している。ノイズ生成＋
フィルター（バンドパス/ローパス）＋緩やかなLFO変調の組み合わせで、それぞれの
音の質感を近似している。ファイルは一切不要で、ライセンス面の懸念もない。

このフォルダは現在未使用。将来的に「本物の環境音を使いたい」となった場合は、
ロイヤリティフリー/CC0の音源に差し替えることも可能（その場合は出典を
このファイルに記録すること）。
